# Love Under Pressure: Caring for Aging Parents and the Risk of Caregivers’ Marital Dissolution

**Author:** Huong Nguyen  
**Last updated:** November 2026

## 1. Project Overview

This project examines the relationship between caring for aging parents and the risk of marital dissolution among adult caregivers.

Although informal caregiving has been shown to affect caregivers' health and labor market outcomes, its potential spillover effects on marital relationships remain understudied. This study investigates whether the demands of caring for aging parents are associated with a higher risk of separation or divorce.

Using longitudinal data from the Health and Retirement Study (HRS), the analysis combines propensity score matching with Cox proportional hazards models to estimate the relationship between parental caregiving and marital dissolution.

The findings indicate that parental caregiving is associated with approximately 51% higher hazard of separation or divorce. Mechanism analyses provide suggestive evidence that this relationship may operate through poorer mental health, weaker labor market attachment, and lower marital satisfaction. The estimated association is stronger among male caregivers than female caregivers.

### 01_Data: Data Sources and Documentation

This directory provides documentation on the datasets required for the analysis.

The study uses two primary data sources:

- **HRS Core Survey Data:** Provides longitudinal information on respondents' demographic characteristics, family relationships, health, employment, and marital status.
- **RAND HRS Longitudinal File:** Provides harmonized longitudinal variables across HRS survey waves.

The original data files are not included in this repository. Researchers must independently obtain the datasets through the official HRS Data Portal.

See `01_Data/README.md` for data sources, access instructions, and data organization details.

### 02_Code: Replication Scripts

This directory contains the Stata do-files used for data preparation, empirical analysis, and robustness checks.

The scripts are intended to be executed in sequence:

1. `01_data_preparation.do`: Prepares the original HRS datasets.
2. `02_merge_core_rand.do`: Merges HRS Core and RAND HRS datasets.
3. `03_sample_construction.do`: Constructs the analytical sample and key study variables.
4. `04_propensity_score_matching.do`: Implements propensity score matching.
5. `05_cox_regression.do`: Estimates the main Cox proportional hazards models.
6. `06_mechanism_analysis.do`: Examines potential mechanisms linking parental caregiving to marital dissolution.
7. `07_robustness_checks.do`: Conducts additional robustness analyses.

File names and script descriptions should be updated to reflect the final replication code.

### 03_Results: Tables and Figures

This directory is designated for the tables, figures, and other outputs generated by the replication scripts.

The repository does not include individual-level HRS data or intermediate datasets. Only outputs that are appropriate for public sharing may be included.

### 04_manuscript: Research Paper

This directory is designated for the manuscript and related research documentation.

## 3. Data Sources and Access

The analysis uses longitudinal HRS data.

Researchers can obtain the required data products through the University of Michigan's Health and Retirement Study Data Portal:

- [HRS Data Portal](https://hrsdata.isr.umich.edu/)
- [HRS Core Survey Data](https://hrsdata.isr.umich.edu/data-products)
- [RAND HRS Longitudinal File](https://hrsdata.isr.umich.edu/data-products/rand)

Researchers must independently register for an HRS account, download the required data products, and comply with the applicable HRS Conditions of Use.

**Data availability:** Original HRS data files and individual-level datasets derived from HRS data are not distributed through this repository.

## 4. Empirical Strategy

The empirical analysis employs the following methods:

- Propensity Score Matching (PSM) to improve comparability between caregivers and non-caregivers.
- Cox Proportional Hazards Models to estimate the association between parental caregiving and the hazard of marital dissolution.
- Mechanism analyses to investigate potential pathways through mental health, labor market attachment, and marital satisfaction.
- Heterogeneity analyses to examine differences by caregiver gender.
- Robustness checks to assess the sensitivity of the main findings.

## 5. Software Requirements

The replication scripts are written in Stata.

Researchers should ensure that they have:
- A compatible version of Stata.
- Access to the required HRS Core and RAND HRS data products.
- The necessary Stata packages used by the replication scripts.

Specific software versions, user-written packages, and dependencies should be documented in the relevant code files.

## 6. Replication Instructions

To reproduce the empirical analysis:

1. Clone or download this repository.
2. Register with the HRS Data Portal and obtain the required HRS datasets.
3. Review `01_Data/README.md` for data organization instructions.
4. Place the downloaded datasets in the appropriate local data directories.
5. Update the directory paths in the Stata do-files.
6. Install any required Stata packages.
7. Execute the scripts in `02_Code/` in the specified order.
8. Review the resulting tables and figures.
